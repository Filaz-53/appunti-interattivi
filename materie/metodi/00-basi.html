Metodi Numerici per l'Analisi dei Dati · capitolo 0

Le basi che servono

Tutta l'algebra lineare e l'analisi che il corso dà per scontate, spiegate da zero e solo nella misura in cui servono per gli altri capitoli. Si legge una volta all'inizio, poi ci si torna quando un capitolo rimanda qui.

§0 · Orientamento

Come usare questo capitolo

Ogni sezione dice dove serve nel corso, spiega l'idea con un esempio numerico e chiude con un paio di domande. Non ci sono dimostrazioni. Se una domanda ti blocca, rileggi l'esempio della sezione: le domande usano gli stessi passaggi.

Tieni carta e penna: le matrici si capiscono facendo i conti a mano almeno una volta.
§1 · Notazione

I simboli che trovi negli appunti

Vocabolario

ℝ: i numeri reali. · ℝⁿ: i vettori con n numeri (ℝ³ = terne come (1, 2, 3)). · ℝᵐˣⁿ: le matrici con m righe e n colonne. · x ∈ A: x appartiene ad A. · ∀: per ogni. · ∃: esiste.
⇒: implica (se vale a sinistra vale a destra). · ⟺: se e solo se (sono equivalenti). · ≈: circa uguale. · ≪: molto più piccolo di.
Σᵢ₌₁ⁿ aᵢ = a₁ + a₂ + … + aₙ (sommatoria). Esempio: Σᵢ₌₁³ i² = 1 + 4 + 9 = 14.
|x|: valore assoluto (|−3| = 3). · ‖x‖: norma, cioè la "lunghezza" di un vettore (capitolo 2).
min f(x): il valore più piccolo che f raggiunge. · argmin f(x): il punto x in cui lo raggiunge. Esempio: per f(x) = (x − 3)² + 1, min = 1 e argmin = 3.
O(n³): il costo cresce come n³ (se raddoppi n, il costo si moltiplica circa per 8).

Verifica · §1

2 domande

Quanto vale Σᵢ₌₁⁴ 2i?

2·1 + 2·2 + 2·3 + 2·4 = 2 + 4 + 6 + 8 = 20.

f(x) = (x + 2)² + 5. Quanto vale argmin f?

Il quadrato è minimo (= 0) quando x + 2 = 0, cioè x = −2: quello è l'argmin. Il valore minimo (min) invece è 5.

§2 · Vettori

Vettori e prodotto scalare

Dove serve: ovunque. Un dato (un cliente, un'immagine) è un vettore; la soluzione di un sistema è un vettore.

Definizione

Un vettore x ∈ ℝⁿ è una lista ordinata di n numeri: x = (x₁, x₂, …, xₙ). xᵢ è la sua i-esima componente. Negli appunti i vettori sono pensati "in colonna", cioè scritti in verticale.

Operazioni: la somma si fa componente per componente: (1, 2) + (3, 5) = (4, 7). Un vettore per un numero moltiplica ogni componente: 3·(1, 2) = (3, 6).

Prodotto scalare

xᵀy = x₁y₁ + x₂y₂ + … + xₙyₙ. Moltiplica componente per componente e somma: il risultato è un numero. Si scrive anche x·y.
Se xᵀy = 0 i vettori sono ortogonali (perpendicolari). La "lunghezza" euclidea è √(xᵀx).

Esempio

x = (1, 2, 3), y = (4, −1, 0)

Soluzione

  1. xᵀy = 1·4 + 2·(−1) + 3·0 = 4 − 2 + 0 = 2

  2. lunghezza di x = √(1 + 4 + 9) = √14 ≈ 3.74

  3. (1, 1) e (1, −1) sono ortogonali: 1·1 + 1·(−1) = 0

Verifica · §2

2 domande

Quanto vale il prodotto scalare tra (2, 0, −1) e (3, 5, 4)?

2·3 + 0·5 + (−1)·4 = 6 + 0 − 4 = 2. Il prodotto scalare è un numero, non un vettore.

Quale vettore è ortogonale a (1, 2)?

1·2 + 2·(−1) = 0. Trucco per ℝ²: scambi le componenti e cambi un segno.

§3 · Matrici

Matrici e i loro tipi

Dove serve: un dataset è una matrice; ogni capitolo dal 2 in poi lavora con le matrici.

Definizione

Una matrice A ∈ ℝᵐˣⁿ è una tabella di numeri con m righe e n colonne (prima le righe, poi le colonne). aᵢⱼ è l'elemento in riga i e colonna j. Negli appunti la si scrive per righe: A = [[1, 2, 3], [4, 5, 6]] ha 2 righe e 3 colonne, e a₂₁ = 4.

I tipi da riconoscere

Quadrata: m = n. · Diagonale principale: gli elementi a₁₁, a₂₂, …, aₙₙ.
Diagonale: tutti zeri fuori dalla diagonale, es. [[3, 0], [0, 5]].
Identità I: diagonale con tutti 1, es. [[1, 0], [0, 1]]. Per le matrici fa quello che fa l'1 per i numeri: AI = IA = A.
Triangolare superiore (U): zeri sotto la diagonale, es. [[2, 1], [0, 3]]. · Triangolare inferiore (L): zeri sopra la diagonale, es. [[2, 0], [5, 3]].
Trasposta Aᵀ: scambia righe e colonne (la riga i diventa la colonna i). Se A è m×n, Aᵀ è n×m. Es. [[1, 2, 3], [4, 5, 6]]ᵀ = [[1, 4], [2, 5], [3, 6]].
Simmetrica: A = Aᵀ, cioè aᵢⱼ = aⱼᵢ (speculare rispetto alla diagonale), es. [[4, 2], [2, 5]].

Verifica · §3

3 domande

Una matrice 4×7 ha…

Si scrive sempre righe × colonne.

Quale di queste matrici è triangolare superiore?

Sotto la diagonale (posizione riga 2, colonna 1) c'è 0. La prima è triangolare inferiore.

A = [[1, 7], [3, 2]]. Quanto vale Aᵀ?

La prima riga (1, 7) diventa la prima colonna. La diagonale resta uguale.

§4 · Prodotto

Prodotto matrice-vettore e matrice-matrice

Dove serve: Ax nei sistemi lineari, LU = A nelle fattorizzazioni, UΣVᵀ nella SVD, AᵀA nei minimi quadrati.

La regola "riga per colonna"

L'elemento in posizione (i, j) di AB è il prodotto scalare tra la riga i di A e la colonna j di B. Si può fare solo se le colonne di A sono tante quante le righe di B: (m×n)·(n×p) = m×p.
Matrice per vettore è un caso particolare: (m×n)·(n×1) = un vettore con m componenti.

Esempio passo per passo

A = [[1, 2], [3, 4]], x = (5, 6), B = [[0, 1], [1, 0]]

Soluzione

  1. Ax: riga 1 · x = 1·5 + 2·6 = 17; riga 2 · x = 3·5 + 4·6 = 39. Quindi Ax = (17, 39).

  2. AB: (1,1): (1,2)·(0,1) = 2; (1,2): (1,2)·(1,0) = 1; (2,1): (3,4)·(0,1) = 4; (2,2): (3,4)·(1,0) = 3. Quindi AB = [[2, 1], [4, 3]].

  3. BA = [[3, 4], [1, 2]], diverso da AB.

  4. Il prodotto tra matrici NON è commutativo: in generale AB ≠ BA

Da ricordare

(AB)ᵀ = BᵀAᵀ (l'ordine si inverte). AᵀA è sempre quadrata (n×n) e simmetrica, anche se A è rettangolare. Per esempio A 100×3 dà AᵀA 3×3: è proprio la matrice dei minimi quadrati. In Python il prodotto si scrive A @ B; A * B invece moltiplica elemento per elemento, che è un'altra cosa.

Verifica · §4

3 domande

[[2, 0], [1, 3]] · (4, 1) = ?

Riga 1: 2·4 + 0·1 = 8. Riga 2: 1·4 + 3·1 = 7.

A è 5×3 e B è 3×2. AB è…

(5×3)·(3×2): le dimensioni interne coincidono, il risultato prende quelle esterne, cioè 5×2.

A è 1000×4. Che dimensione ha AᵀA?

Aᵀ è 4×1000; (4×1000)·(1000×4) = 4×4.

§5 · Sistemi

Un sistema lineare è Ax = b

Dove serve: capitoli 3, 5 e 6.

Il sistema { 2x₁ + x₂ = 5 ; x₁ + x₂ = 3 } si scrive in forma compatta Ax = b, con A = [[2, 1], [1, 1]] (i coefficienti), x = (x₁, x₂) (le incognite) e b = (5, 3) (i termini noti). Infatti Ax, con la regola di §4, dà proprio (2x₁ + x₂, x₁ + x₂).

Esempio

Risolvere a mano per sottrazione

Soluzione

  1. Sottraggo la seconda equazione dalla prima: (2x₁ + x₂) − (x₁ + x₂) = 5 − 3, quindi x₁ = 2.

  2. Sostituisco nella seconda: 2 + x₂ = 3, quindi x₂ = 1.

  3. x = (2, 1). Verifica: A·(2, 1) = (5, 3) = b ✓

"Sottrarre un multiplo di un'equazione da un'altra per eliminare un'incognita" è esattamente l'eliminazione di Gauss del capitolo 3, fatta in modo sistematico.

Un sistema può avere: una soluzione sola; nessuna (es. x + y = 1 e x + y = 2: equazioni contraddittorie); infinite (es. x + y = 1 e 2x + 2y = 2: la seconda è la prima ripetuta).

§6 · Inversa

Determinante e matrice inversa

Dove serve: condizionamento (capitolo 5), "singolare" e "invertibile" ovunque.

Matrici 2×2 (basta saperlo per queste)

Per A = [[a, b], [c, d]]: det(A) = ad − bc.
Se det(A) ≠ 0, A è invertibile (non singolare) e A⁻¹ = (1/det)·[[d, −b], [−c, a]]: si scambiano i due elementi della diagonale, si cambia segno agli altri due e si divide per il determinante.
L'inversa è la matrice tale che AA⁻¹ = A⁻¹A = I. Se det(A) = 0 la matrice è singolare e l'inversa non esiste.

Esempio

A = [[2, 1], [1, 1]]

Soluzione

  1. det = 2·1 − 1·1 = 1

  2. A⁻¹ = (1/1)·[[1, −1], [−1, 2]] = [[1, −1], [−1, 2]]

  3. Verifica: AA⁻¹ = [[2−1, −2+2], [1−1, −1+2]] = [[1, 0], [0, 1]] = I ✓

Per una matrice triangolare il determinante è il prodotto degli elementi sulla diagonale.

Verifica · §6

2 domande

Quale matrice è singolare?

det = 2·2 − 4·1 = 0. Le altre hanno det −2 e 5.

A = [[4, 1], [2, 1]]. Quanto vale A⁻¹?

det = 4 − 2 = 2. A⁻¹ = ½·[[1, −1], [−2, 4]] = [[0.5, −0.5], [−1, 2]]. La seconda opzione dimentica di dividere per il determinante.

§7 · Struttura

Indipendenza lineare, rango, immagine e nucleo

Dove serve: capitolo 4 (rango dalla SVD) e capitolo 6 (unicità dei minimi quadrati).

Le idee (intuitive)

Combinazione lineare di vettori: sommarli dopo averli moltiplicati per dei numeri, es. 2v₁ − 3v₂.
Dei vettori sono linearmente indipendenti se nessuno si ottiene come combinazione degli altri, cioè nessuno è "ridondante". (1, 2) e (2, 4) sono dipendenti, perché il secondo è il doppio del primo.
span di alcuni vettori: tutte le loro combinazioni lineari. Lo span di (1,0) e (0,1) è tutto il piano ℝ².
Rango di A, rank(A): quante colonne linearmente indipendenti ha, cioè quante "direzioni davvero diverse" contiene.
Immagine Im(A): lo span delle colonne, cioè tutti i possibili Ax. · Nucleo ker(A): i vettori x con Ax = 0.

Esempio

A = [[1, 2], [2, 4]]

Soluzione

  1. La colonna 2, (2, 4), è il doppio della colonna 1, (1, 2): sono dipendenti, quindi rank(A) = 1.

  2. det = 4 − 4 = 0, quindi è singolare. Per una matrice quadrata n×n vale: rango n ⟺ det ≠ 0 ⟺ invertibile.

  3. x = (2, −1) sta nel nucleo: A·(2, −1) = (2−2, 4−4) = (0, 0)

Verifica · §7

2 domande

Qual è il rango di [[1, 3], [2, 6], [3, 9]]?

La seconda colonna è 3 volte la prima: c'è una sola direzione indipendente.

A è 3×3 con rango 3. Allora…

Rango pieno ⟺ det ≠ 0 ⟺ invertibile, e Ax = b ha un'unica soluzione.

§8 · Autovalori

Autovalori e autovettori

Dove serve: capitolo 3 §5, capitolo 4 (σᵢ = √autovalori di AᵀA) e capitolo 9 (classificare i minimi con l'Hessiana).

Definizione

v ≠ 0 è un autovettore di A (quadrata) con autovalore λ se Av = λv: A non cambia la direzione di v, lo allunga o accorcia di un fattore λ.
Come si calcolano (2×2): si risolve det(A − λI) = 0, un'equazione di secondo grado in λ. A − λI vuol dire sottrarre λ agli elementi della diagonale.

Esempio

A = [[2, 1], [1, 2]]

Soluzione

  1. A − λI = [[2−λ, 1], [1, 2−λ]], quindi det = (2−λ)² − 1.

  2. (2−λ)² = 1 ⇒ 2 − λ = ±1 ⇒ λ = 1 oppure λ = 3.

  3. Verifica con v = (1, 1): Av = (3, 3) = 3·(1, 1) ✓ (autovalore 3). Con v = (1, −1): Av = (1, −1) = 1·(1, −1) ✓ (autovalore 1).

  4. Gli autovalori sono 1 e 3, entrambi positivi: A è definita positiva (capitolo 3)

Per una matrice diagonale o triangolare gli autovalori sono gli elementi della diagonale: non serve calcolare niente.

Verifica · §8

2 domande

Quali sono gli autovalori di [[5, 0], [0, −2]]?

È diagonale: gli autovalori sono gli elementi sulla diagonale.

Av = 4v con v = (1, 2). Quanto vale A·(1, 2)?

Per definizione Av = λv = 4·(1, 2) = (4, 8).

§9 · Analisi

Derivate, gradiente e Hessiana

Dove serve: capitolo 8 (Newton usa f′) e capitolo 9 (gradiente e Hessiana).

Derivata (una variabile)

f′(x) è la pendenza di f nel punto x: positiva se f sale, negativa se scende, zero nei punti di massimo o minimo (tangente orizzontale).
Regole: (c)′ = 0 · (xⁿ)′ = n·xⁿ⁻¹ · (eˣ)′ = eˣ · (ln x)′ = 1/x · (sin x)′ = cos x · (cos x)′ = −sin x · (f + g)′ = f′ + g′ · (c·f)′ = c·f′ · catena: (f(g(x)))′ = f′(g(x))·g′(x), es. (e^(3x))′ = 3e^(3x).
La derivata seconda f″ è la derivata di f′ e dice la curvatura: f″ > 0 vuol dire concava verso l'alto, cioè forma a ∪.

Più variabili

Per f(x, y), la derivata parziale ∂f/∂x si calcola derivando rispetto a x e trattando y come una costante (e viceversa).
Il gradiente ∇f = (∂f/∂x, ∂f/∂y) è il vettore delle derivate parziali e punta nella direzione in cui f cresce più in fretta.
L'Hessiana ∇²f è la matrice delle derivate seconde [[∂²f/∂x², ∂²f/∂x∂y], [∂²f/∂y∂x, ∂²f/∂y²]]. È simmetrica ed è la "f″" in più variabili.

Esempio

f(x, y) = x² + 3xy

Soluzione

  1. ∂f/∂x: y è una costante, quindi 2x + 3y. ∂f/∂y: x è una costante, quindi 0 + 3x = 3x.

  2. ∇f = (2x + 3y, 3x). Nel punto (1, 2): ∇f = (2 + 6, 3) = (8, 3).

  3. Hessiana: ∂²f/∂x² = 2, ∂²f/∂x∂y = 3, ∂²f/∂y² = 0, quindi ∇²f = [[2, 3], [3, 0]]

Verifica · §9

3 domande

f(x) = x³ − 2x. Quanto vale f′(2)?

f′(x) = 3x² − 2, quindi f′(2) = 12 − 2 = 10.

f(x, y) = x²y + y. Quanto vale ∂f/∂y?

Con x costante: x²y ha derivata x² rispetto a y, e y ha derivata 1. 2xy è invece ∂f/∂x.

Il gradiente di f in un punto indica…

Per scendere verso il minimo si va nella direzione opposta, −∇f: è il metodo del gradiente del capitolo 9.
