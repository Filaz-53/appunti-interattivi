Metodi Numerici per l'Analisi dei Dati · capitolo 9

Ottimizzazione numerica

Trovare il minimo di una funzione di più variabili: come riconoscerlo (gradiente e Hessiana) e come raggiungerlo (metodi di discesa, gradiente, scelta del passo). Addestrare un modello di ML vuol dire esattamente questo: minimizzare la loss.

§0 · Orientamento

Cosa chiedono all'esame

  • Classificare un punto stazionario dagli autovalori dell'Hessiana: minimo, massimo o sella.
  • Calcolare il gradiente di una funzione semplice e trovare i punti stazionari.
  • Convessità: minimo locale = globale; una quadratica è convessa ⟺ Q è semidefinita positiva.
  • Direzione di discesa: pᵀ∇f < 0; l'antigradiente lo è sempre.
  • Passo: effetto di α troppo grande o troppo piccolo; condizione di Armijo e backtracking.
  • Probabilmente il prossimo homework riguarda il gradiente: va preparato anche per l'orale.
§1 · Formulazione

Il problema di minimo

Si cerca argmin_{x∈Ω} f(x), con f: Ω ⊆ ℝⁿ → ℝ. Il massimo si riconduce al minimo: argmax f = argmin (−f). Ω è l'insieme dei vincoli: con Ω = ℝⁿ il problema è non vincolato (quello che si fa nel corso), con Ω ⊂ ℝⁿ è vincolato. Se f è lineare il problema si dice lineare, se è quadratica si dice quadratico.

Definizioni

x* è un minimo locale se f(x*) ≤ f(x) per ogni x in un intorno di x* (stretto se vale < per x ≠ x*). È un minimo globale se f(x*) ≤ f(x) per ogni x ∈ ℝⁿ. Una funzione può avere minimi locali e nessun globale, nessun minimo, o entrambi i tipi.

§2 · Teoria

Condizioni di ottimalità

Primo ordine (necessaria)

Se x* è un minimo locale e f è differenziabile con continuità, allora ∇f(x*) = 0. Un punto con ∇f = 0 si chiama stazionario. La condizione non è sufficiente: un punto stazionario può essere un minimo, un massimo o una sella.

Matrici definite e autovalori (A simmetrica)

Definita positiva: xᵀAx > 0 ⟺ tutti gli autovalori > 0. · Semidefinita positiva: autovalori ≥ 0. · Definita negativa: autovalori < 0. · Indefinita: autovalori di segno discorde.

Secondo ordine

Necessaria: se x* è un minimo locale, allora ∇f(x*) = 0 e ∇²f(x*) è semidefinita positiva.
Sufficiente: se ∇f(x*) = 0 e l'Hessiana ∇²f(x*) è definita positiva si ha un minimo locale stretto; se è definita negativa un massimo locale stretto; se è indefinita una sella.

Trappola

Se l'Hessiana è solo semidefinita, per esempio nulla, non si può concludere. Esempi: x⁴, x³ e −x⁴ hanno tutte f′(0) = 0 e f″(0) = 0, ma in 0 hanno rispettivamente un minimo, un flesso e un massimo.

Esercizio della prof · classificare

f₁ = x² + 4y², f₂ = x² − y², f₃ = −x² − y²

Soluzione

  1. Tutte hanno ∇f = 0 solo in (0, 0): ∇f₁ = (2x, 8y), ∇f₂ = (2x, −2y), ∇f₃ = (−2x, −2y).

  2. Hessiane: f₁ → diag(2, 8), autovalori > 0, minimo. f₂ → diag(2, −2), segni discordi, sella. f₃ → diag(−2, −2), autovalori < 0, massimo.

§3 · Convessità

Il caso convesso

Definizione e teorema

f è convessa se f(αx + (1−α)y) ≤ αf(x) + (1−α)f(y) per ogni α ∈ [0,1] (strettamente con <).
Se f è convessa, ogni minimo locale è globale. Se è strettamente convessa, il minimo globale (se esiste) è unico. Se è convessa e differenziabile, ogni punto stazionario è un minimo globale.

Quadratiche

q(x) = ½xᵀQx + cᵀx + b, con Q simmetrica: ∇q = Qx + c e ∇²q = Q. q è convessa ⟺ Q è semidefinita positiva, strettamente convessa ⟺ Q è definita positiva. Il minimo risolve Qx = −c: minimizzare una quadratica equivale a risolvere un sistema lineare. Anche i minimi quadrati ‖Ax − b‖² sono una quadratica, con Q = 2AᵀA.

§4 · Algoritmi

Metodi di discesa

A partire da x₀ si genera xₖ₊₁ = xₖ + αₖpₖ, con pₖ direzione di ricerca e αₖ > 0 lunghezza del passo (learning rate), scelti in modo che f(xₖ₊₁) < f(xₖ).

Direzione di discesa

p è di discesa in x se f(x + αp) < f(x) per ogni α ∈ (0, ᾱ]. Proposizione: se pᵀ∇f(x) < 0 (angolo ottuso con il gradiente) p è di discesa. Se pᵀ∇f > 0 è di salita. Se pᵀ∇f = 0 non si può dire niente.

L'antigradiente p = −∇f(x) è sempre di discesa se ∇f ≠ 0, perché pᵀ∇f = −‖∇f‖² < 0. È la direzione di massima discesa.

Trappola (esempio della prof)

f(x₁,x₂) = x₁³ + x₂² − 3x₁ in x = (−1, 0) con p = (−1, 0): il gradiente è (0, 0), quindi pᵀ∇f = 0, eppure f(x + tp) = −t³ + cost decresce: p è di discesa anche se pᵀ∇f = 0. La condizione pᵀ∇f < 0 è sufficiente, non necessaria.

Scendere non basta

Con min x², x₀ = −3, pₖ = 1 e αₖ = 2⁻ᵏ ogni passo scende, ma xₖ → −1, che non è stazionario. Se i passi si accorciano troppo in fretta ci si ferma prima del minimo: il passo va scelto bene.

§5 · Gradiente

Il metodo del gradiente e la scelta del passo

Metodo del gradiente

xₖ₊₁ = xₖ − αₖ∇f(xₖ)

Ci si ferma quando ‖∇f(xₖ)‖ < tol (anche relativo, ‖∇f(xₖ)‖/‖∇f(x₀)‖), oppure quando si raggiunge il massimo numero di iterazioni. Con una ricerca del passo adeguata il teorema di Zoutendijk garantisce la convergenza a un punto stazionario.

Passo costante α

È semplice ma dipende dalla scala del problema. α troppo piccolo: gli iterati "stallano" e servono moltissime iterazioni. α troppo grande: gli iterati oscillano tra le pareti della valle e non convergono (o divergono). α giusto: converge a un punto stazionario.

Ricerca in linea inesatta: Armijo e backtracking

Condizione di Armijo (decrescita sufficiente): f(xₖ + αpₖ) ≤ f(xₖ) + c₁·α·∇f(xₖ)ᵀpₖ, con 0 < c₁ < 1. Insieme alla condizione di curvatura forma le condizioni di Wolfe.
Backtracking: si parte da α = α₀ (di solito 1) e lo si riduce (per esempio α ← α/2) finché Armijo è soddisfatta. Con il backtracking, Armijo da sola basta a garantire la convergenza.


def backtracking(f, grad, x, p, alpha=1.0, c1=1e-4, rho=0.5):
    while f(x + alpha * p) > f(x) + c1 * alpha * grad(x) @ p:
        alpha *= rho
    return alpha

def gradiente(f, grad, x0, tol=1e-6, maxit=1000):
    x = x0
    for k in range(maxit):
        g = grad(x)
        if np.linalg.norm(g) < tol: break
        p = -g
        x = x + backtracking(f, grad, x, p) * p
    return x, k

Il gradiente converge solo linearmente. Nel ML si usa la versione stocastica: si calcola il gradiente della loss su un sottoinsieme di dati (mini-batch) per risparmiare.

5 domande

In un punto stazionario l'Hessiana ha autovalori 4 e 1. Il punto è…

Tutti gli autovalori > 0 vuol dire Hessiana definita positiva, quindi minimo locale stretto.

f(x, y) = x² + 2y² − 4x. Dov'è il punto stazionario?

∇f = (2x − 4, 4y) = 0 dà x = 2, y = 0. Hessiana diag(2, 4), definita positiva: è il minimo globale (f è convessa).

∇f(x) = (2, −1) e p = (−1, 1). p è una direzione di discesa?

pᵀ∇f = (−1)(2) + (1)(−1) = −3 < 0, quindi è di discesa.

Se f è convessa e differenziabile, un punto con ∇f = 0 è…

Nel caso convesso ogni punto stazionario è un minimo globale.

Nel backtracking, se la condizione di Armijo non è soddisfatta…

Si parte da un passo grande e lo si accorcia (α ← ρα) finché la decrescita è sufficiente.

§6 · Allenamento

Esercizi e ripasso

Esercizio 6.1 · un passo di gradiente a mano

f(x, y) = x² + 4y², x₀ = (2, 1), α = 0.1

Quanto vale x₁?

∇f = (2x, 8y) = (4, 8). x₁ = (2, 1) − 0.1·(4, 8) = (1.6, 0.2). (2.4, 1.8) si ottiene andando nella direzione del gradiente, cioè salendo.

Soluzione

  1. ∇f(x, y) = (2x, 8y), quindi ∇f(2, 1) = (4, 8).

  2. x₁ = x₀ − α∇f = (2 − 0.4, 1 − 0.8) = (1.6, 0.2).

  3. f(x₀) = 4 + 4 = 8 e f(x₁) = 2.56 + 0.16 = 2.72: la funzione è scesa ✓
