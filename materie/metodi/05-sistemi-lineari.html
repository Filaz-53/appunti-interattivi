Sistemi lineari e condizionamento

Come si risolve Ax = b in pratica (fattorizzazione e due sostituzioni) e quanto ci si può fidare della soluzione calcolata (numero di condizionamento). È il cuore dell'HW1, es. 3.

Prima di iniziare · cosa ti serve

sistemi come Ax = b (cap. 0 §5) · inversa e determinante (cap. 0 §6) · matrici triangolari (cap. 0 §3) · il capitolo 3 (LU e Cholesky) e il capitolo 2 (norme). Se qualcosa non ti è chiaro, parti da lì: questo capitolo lo dà per scontato.

§0 · Orientamento

Cosa chiedono all'esame

  • Costi: sostituzione O(n²), fattorizzazione O(n³).
  • Sequenza di risoluzione con LU, con PA = LU e con Cholesky: quale sistema si risolve per primo, con quale termine noto.
  • Perché non si calcola A⁻¹.
  • K(A) = ‖A‖‖A⁻¹‖, K₂ = σ_max/σ_min, la stima dell'errore e le cifre perse ≈ log₁₀K.
  • "Residuo piccolo implica errore piccolo?" No, se A è mal condizionata.
  • All'orale: perché l'errore su Hilbert esplode con n.
§1 · Teoria

Esistenza e unicità, metodi diretti e iterativi

Condizioni equivalenti (A quadrata)

A non singolare ⟺ det(A) ≠ 0 ⟺ rank(A) = n ⟺ ker(A) = {0} ⟺ esiste A⁻¹ ⟺ per ogni b il sistema ha un'unica soluzione. Se A è singolare: nessuna soluzione o infinite, a seconda di b.

Perché non si calcola A⁻¹

x = A⁻¹b vale in teoria, ma calcolare l'inversa richiede più operazioni, più memoria (tutta la matrice inversa) e introduce più errori di arrotondamento. Inoltre calcola informazioni che non servono. Si risolve direttamente il sistema.

Metodi diretti: danno la soluzione in un numero finito di operazioni (in aritmetica esatta) e si basano su Gauss e sulle fattorizzazioni. Metodi iterativi: costruiscono x⁽⁰⁾, x⁽¹⁾, … che converge alla soluzione, e sono adatti a matrici grandi e sparse.

§2 · Triangolari

Sostituzione in avanti e all'indietro

Le due formule

In avanti (Lx = b, L triangolare inferiore): xᵢ = (bᵢ − Σⱼ<ᵢ ℓᵢⱼxⱼ) / ℓᵢᵢ, con i = 1, …, n.
All'indietro (Ux = b, U triangolare superiore): xᵢ = (bᵢ − Σⱼ>ᵢ uᵢⱼxⱼ) / uᵢᵢ, con i = n, …, 1.

Costo: le somme hanno in tutto 1 + 2 + … + (n−1) = n(n−1)/2 termini, quindi circa n² operazioni, cioè O(n²). Molto meno dell'O(n³) della fattorizzazione.

  1. SostituzioneIndietro(U, b, n)
  2. per i = n fino a 1
  3. s = b[i]
  4. per j = i+1 a n: s = s − U[i,j]·x[j]
  5. x[i] = s / U[i,i]
  6. ritorna x
§3 · Con le fattorizzazioni

Risolvere con LU, PA = LU e Cholesky

Le tre sequenze

A = LU: LUx = b. Posto y = Ux: (1) Ly = b in avanti, (2) Ux = y all'indietro.
PA = LU: PAx = Pb, quindi LUx = Pb: (1) Ly = Pb, (2) Ux = y. Il termine noto va permutato.
A = LLᵀ: (1) Ly = b, (2) Lᵀx = y.

Costo totale ≈ O(n³) per la fattorizzazione + O(n²) per le sostituzioni. Se cambia solo b si riusa la fattorizzazione e si pagano solo le due sostituzioni.

Esempio della prof · LU

A = [[2,1,1],[4,−6,0],[−2,7,2]], b = (5, −2, 9)

Dal capitolo 3: L = [[1,0,0],[2,1,0],[−1,−1,1]], U = [[2,1,1],[0,−8,−2],[0,0,1]].

Soluzione

  1. Ly = b: y₁ = 5; 2·5 + y₂ = −2 → y₂ = −12; −5 + 12 + y₃ = 9 → y₃ = 2.

  2. Ux = y: x₃ = 2; −8x₂ − 2·2 = −12 → x₂ = 1; 2x₁ + 1 + 2 = 5 → x₁ = 1.

  3. x = (1, 1, 2)

Esempio della prof · PA = LU

A = [[0,2,1],[1,−2,−3],[2,3,1]], b = (3, 0, 7)

Soluzione

  1. P scambia le righe 1 e 3, quindi Pb = (7, 0, 3).

  2. Con L = [[1,0,0],[1/2,1,0],[0,−4/7,1]], Ly = Pb dà y = (7, −7/2, 1).

  3. Ux = y con U = [[2,3,1],[0,−7/2,−7/2],[0,0,−1]] dà x = (1, 2, −1)


from scipy.linalg import lu_factor, lu_solve
x_esatta = np.ones(n);  b = A @ x_esatta          # problema test con soluzione nota
x = lu_solve(lu_factor(A), b)
err_rel = np.linalg.norm(x - x_esatta) / np.linalg.norm(x_esatta)

L = np.linalg.cholesky(A)                         # solo se A è simmetrica definita positiva
y = scipy.linalg.solve_triangular(L, b, lower=True)
x = scipy.linalg.solve_triangular(L.T, y)

Verifica · §2–§3

3 domande

Quanto costa risolvere un sistema triangolare n×n?

Circa n²/2 moltiplicazioni. O(n³) è il costo della fattorizzazione.

Con PA = LU, il primo sistema da risolvere è…

Da PAx = Pb si ottiene LUx = Pb: prima si permuta il termine noto.

Si deve risolvere Ax = b per 100 vettori b diversi, con la stessa A n×n. Qual è il costo complessivo migliore?

Si fattorizza una volta sola e poi si fanno due sostituzioni per ogni b.

§4 · Affidabilità

Condizionamento dei sistemi lineari

Si confronta il sistema esatto Ax = b con quello perturbato (A + ΔA)(x + δx) = b + δb. Il problema è ben condizionato se piccole perturbazioni relative dei dati danno piccole variazioni relative della soluzione.

Esempio della prof · perturbazione

A = [[1, 2], [0.499, 1.001]], b = (3, 1.5)

Soluzione

  1. La soluzione è x = (1, 1).

  2. Si cambiano due elementi: Ã = [[1, 2], [0.500, 1.002]]. La perturbazione relativa di A è ≈ 5.7·10⁻⁴.

  3. La nuova soluzione è x̃ = (3, 0): il cambiamento relativo ≈ 1.58. L'errore è amplificato di circa 3000 volte.

Numero di condizionamento

K(A) = ‖A‖·‖A⁻¹‖ ≥ 1 (norma indotta). Se si perturba solo b:

‖δx‖/‖x‖ ≤ K(A) · ‖δb‖/‖b‖

Se si perturbano A e b, al primo ordine: ‖δx‖/‖x‖ ≲ K(A)·(‖ΔA‖/‖A‖ + ‖δb‖/‖b‖).
In norma 2: K₂(A) = σ_max/σ_min. Un σ_min piccolo vuol dire A quasi singolare e K grande.

Regole pratiche: K vicino a 1 vuol dire ben condizionata. Si perdono circa log₁₀K(A) cifre decimali: in doppia precisione si hanno circa 16 cifre, quindi ne restano circa 16 − log₁₀K. np.linalg.cond(A) usa la norma 2.

La matrice di Hilbert

Hᵢⱼ = 1/(i + j − 1). K₂(H) cresce in modo esplosivo: n = 2 → 19; n = 5 → 4.8·10⁵; n = 8 → 1.5·10¹⁰; n = 10 → 1.6·10¹³. Per n ≳ 12 supera 1/eps ≈ 10¹⁶ e la soluzione calcolata non ha più cifre corrette.

Trappole

1. Un residuo piccolo ‖b − Ax̂‖ non garantisce un errore piccolo ‖x − x̂‖ se K è grande. 2. Un algoritmo stabile (per esempio LU con pivoting) non elimina il mal condizionamento: quello è del problema. 3. Il valore di K dipende dalla norma scelta.

Verifica · §4

3 domande

K(A) = 10³ e l'errore relativo su b è 10⁻⁶. Quanto vale al massimo l'errore relativo su x?

‖δx‖/‖x‖ ≤ K·‖δb‖/‖b‖ = 10³·10⁻⁶ = 10⁻³.

Per ogni matrice invertibile, K(A) è…

1 = ‖I‖ = ‖AA⁻¹‖ ≤ ‖A‖‖A⁻¹‖. Il determinante non misura il condizionamento.

Nell'HW1, su Hilbert con n = 15, l'errore di fattorizzazione ‖PA − LU‖ è ≈ 10⁻¹⁷ ma l'errore sulla soluzione è grande. Perché?

La fattorizzazione è accurata (l'algoritmo è stabile), ma K enorme amplifica gli arrotondamenti: K·eps ≫ 1.

§5 · Allenamento

Esercizi e ripasso

Esercizio 5.1 · da calcolatrice

K∞ di una 2×2

A = [[2, 1], [1, 1]]. Calcola K∞(A) = ‖A‖∞‖A⁻¹‖∞.

K∞(A) = ?

‖A‖∞ = max(3, 2) = 3. A⁻¹ = [[1, −1], [−1, 2]] (det = 1), quindi ‖A⁻¹‖∞ = max(2, 3) = 3. K = 9.

Soluzione

  1. ‖A‖∞: somme per righe 3 e 2, quindi 3.

  2. det = 2 − 1 = 1, quindi A⁻¹ = [[1, −1], [−1, 2]]; somme per righe 2 e 3, quindi ‖A⁻¹‖∞ = 3.

  3. K∞(A) = 3·3 = 9
