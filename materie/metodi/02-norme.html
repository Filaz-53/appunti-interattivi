Norme di vettori e matrici

Le norme misurano la "grandezza" di vettori e matrici. Servono ovunque nel corso: per misurare gli errori, per definire il condizionamento K(A) = ‖A‖‖A⁻¹‖ e per i residui dei minimi quadrati.

Prima di iniziare · cosa ti serve

vettori e prodotto scalare (cap. 0 §2) · matrici, righe e colonne (cap. 0 §3) · prodotto matrice-vettore (cap. 0 §4). Se qualcosa non ti è chiaro, parti da lì: questo capitolo lo dà per scontato.

§0 · Orientamento

Cosa chiedono all'esame

  • Calcolare a mano ‖x‖₁, ‖x‖₂, ‖x‖∞ di un vettore e ‖A‖₁, ‖A‖∞, ‖A‖_F di una matrice piccola: punti sicuri.
  • Ricordare quale norma va per righe e quale per colonne: è la trappola classica.
  • Conoscere le 4 proprietà di una norma e la submoltiplicatività ‖AB‖ ≤ ‖A‖‖B‖.
  • Sapere che ‖A‖₂ = √ρ(AᵀA) = σ₁ (il collegamento con la SVD arriva nel capitolo 4).
§1 · Motivazione

I dati sono matrici

Un dataset è una matrice X: ogni riga è un'osservazione (un cliente, un'immagine, un documento) e ogni colonna è una caratteristica. Ogni osservazione è quindi un vettore. Anche un'immagine in scala di grigi è una matrice di intensità, e un testo diventa un vettore di frequenze o un embedding.

Da qui tutti gli strumenti del corso:

  • distanze e norme dicono quali oggetti si somigliano;
  • con un prodotto matrice-vettore ŷ = Xw si fanno tutte le previsioni di un modello lineare insieme;
  • rango e SVD trovano ridondanze e comprimono i dati;
  • il condizionamento dice se ci si può fidare del risultato numerico.
Questa parte è discorsiva: all'esame al massimo una domanda del tipo "in un dataset, cosa rappresentano righe e colonne?".
§2 · Vettori

Norme vettoriali

Definizione

‖·‖: ℝⁿ → ℝ è una norma se, per ogni x, y ∈ ℝⁿ e α ∈ ℝ: 1. ‖x‖ ≥ 0; 2. ‖x‖ = 0 ⟺ x = 0; 3. ‖αx‖ = |α|‖x‖; 4. ‖x + y‖ ≤ ‖x‖ + ‖y‖ (disuguaglianza triangolare). La quantità ‖x − y‖ è la distanza tra x e y.

Le norme p

‖x‖ₚ = (Σ|xᵢ|ᵖ)^(1/p), con 1 ≤ p < ∞. I casi usati sono questi:
‖x‖₁ = Σ|xᵢ| · ‖x‖₂ = √(Σxᵢ²) (euclidea) · ‖x‖∞ = max|xᵢ|

Esempio della prof

x = (1, −2, 2)ᵀ

Soluzione

  1. ‖x‖₁ = 1 + 2 + 2 = 5

  2. ‖x‖₂ = √(1 + 4 + 4) = √9 = 3

  3. ‖x‖∞ = max(1, 2, 2) = 2

Vale sempre ‖x‖∞ ≤ ‖x‖₂ ≤ ‖x‖₁, come si vede dall'esempio: 2 ≤ 3 ≤ 5. Utile per scartare subito un'opzione sbagliata.

La sfera unitaria {x : ‖x‖ ≤ 1} cambia forma con la norma: in ℝ² è un rombo per ‖·‖₁, un cerchio per ‖·‖₂ e un quadrato per ‖·‖∞. In dimensione finita però tutte le norme sono equivalenti: danno valori diversi ma lo stesso concetto di convergenza.

Verifica · §2

2 domande

x = (3, −4, 0)ᵀ. Quanto vale ‖x‖₂?

√(9 + 16 + 0) = 5. Invece 7 è ‖x‖₁ e 4 è ‖x‖∞.

In ℝ², la sfera unitaria della norma ∞ è…

max(|x₁|, |x₂|) ≤ 1 è il quadrato [−1,1]². Il rombo è la norma 1, il cerchio la norma 2.

§3 · Matrici

Norme matriciali

Una norma matriciale soddisfa le stesse 4 proprietà. Per essere compatibile con il prodotto si chiede anche la submoltiplicatività ‖AB‖ ≤ ‖A‖‖B‖, che è fondamentale per studiare come si propagano gli errori.

Norma indotta

Fissata una norma vettoriale: ‖A‖ = max_{x≠0} ‖Ax‖/‖x‖ = max_{‖x‖=1} ‖Ax‖. È il massimo fattore di amplificazione che A applica a un vettore. Per costruzione è consistente: ‖Ax‖ ≤ ‖A‖‖x‖.

Le formule da sapere

‖A‖₁ = max_j Σᵢ|aᵢⱼ|, la massima somma dei moduli per colonna.
‖A‖∞ = max_i Σⱼ|aᵢⱼ|, la massima somma dei moduli per riga.
‖A‖₂ = √ρ(AᵀA), dove ρ è il raggio spettrale, cioè il massimo autovalore in modulo. Equivale a σ₁, il massimo valore singolare.
‖A‖_F = (Σᵢ Σⱼ |aᵢⱼ|²)^(1/2) = √tr(AᵀA) (Frobenius).

Trucco mnemonico: l'"1" è un tratto verticale, quindi colonne; il "∞" è sdraiato, quindi righe.
Trappola

La norma di Frobenius è submoltiplicativa e consistente con la norma 2, ma non è indotta da nessuna norma vettoriale. Infatti ‖I‖_F = √n, mentre ogni norma indotta dà ‖I‖ = 1.

Esempio della prof

A = [[1, −2], [3, 4]]

Soluzione

  1. ‖A‖₁: le colonne sommano |1|+|3| = 4 e |−2|+|4| = 6, quindi 6.

  2. ‖A‖∞: le righe sommano |1|+|−2| = 3 e |3|+|4| = 7, quindi 7.

  3. ‖A‖_F = √(1 + 4 + 9 + 16) = √30 ≈ 5.477.

  4. ‖A‖₂ ≈ 5.117: a mano richiede gli autovalori di AᵀA, quindi allo scritto di solito non la chiedono. Notare che ‖A‖₂ ≤ ‖A‖_F.

Verifica · §3

3 domande

A = [[2, −1, 0], [1, 3, −4], [0, 5, 1]]. Quanto vale ‖A‖₁?

Per colonne: 2+1+0 = 3; 1+3+5 = 9; 0+4+1 = 5, quindi il massimo è 9. Per righe (‖A‖∞) si avrebbe 3, 8, 6, cioè 8: è la risposta-trappola.

Quanto vale ‖I‖_F per la matrice identità 4×4?

√(1+1+1+1) = 2. Una norma indotta darebbe 1: questa è la prova che Frobenius non è indotta.

Cosa misura la norma indotta ‖A‖?

‖A‖ = max ‖Ax‖/‖x‖. Per questo nel condizionamento compare ‖A‖‖A⁻¹‖: quanto si amplificano gli errori.

§4 · Codice

In Python


import numpy as np
x = np.array([1., -2., 2.])
np.linalg.norm(x, 1), np.linalg.norm(x), np.linalg.norm(x, np.inf)   # 5, 3, 2

A = np.array([[1., -2.], [3., 4.]])
np.linalg.norm(A, 1)       # 6     (colonne)
np.linalg.norm(A, np.inf)  # 7     (righe)
np.linalg.norm(A, 2)       # 5.117 (sigma_1)
np.linalg.norm(A, 'fro')   # 5.477 (Frobenius, il default per le matrici)
Per l'orale

np.linalg.norm(A) senza secondo argomento su una matrice restituisce Frobenius, non la norma 2. Negli homework, per gli errori di fattorizzazione e di compressione, è bene sapere quale norma si sta usando.

§5 · Allenamento

Esercizi e ripasso

Esercizio 5.1 · stile scritto

Errore relativo in norma

La soluzione esatta di un sistema è x = (1, 1, 1)ᵀ e quella calcolata è x̃ = (1.01, 0.98, 1.00)ᵀ. Calcola l'errore relativo in norma ∞.

‖x − x̃‖∞ / ‖x‖∞ = ?

x − x̃ = (−0.01, 0.02, 0), con massimo in modulo 0.02, e ‖x‖∞ = 1. In norma 1 verrebbe 0.03/3 = 0.01.

Soluzione

  1. x − x̃ = (−0.01, 0.02, 0)ᵀ, quindi ‖x − x̃‖∞ = 0.02.

  2. Errore relativo = 0.02 / 1 = 0.02 = 2%

Checklist: sai farlo senza guardare?
La norma 2 di una matrice si calcola come la norma 2 di un vettore? No

Quella che "somma i quadrati di tutti gli elementi" è Frobenius. La norma 2 matriciale è σ₁ = √ρ(AᵀA).

Norme diverse possono dare risultati diversi di convergenza? No

In dimensione finita tutte le norme sono equivalenti: se una successione converge in una norma, converge in tutte.
