Esercizio 1: complessità passo passo

L'esercizio 1 c'è in tutti i 18 scritti dal 2024 al 2026: «calcolare la complessità T(n) di mystery1». Qui c'è solo quello che serve per risolverlo, con la notazione delle soluzioni ufficiali. La teoria completa è nel capitolo 2.

Prima di iniziare · cosa ti serve

Potenze e logaritmi (log₂ n = quante volte dimezzi n per arrivare a 1: log₂ 8 = 3, perché 8 → 4 → 2 → 1) · le sommatorie Σ · cos'è una funzione ricorsiva. La definizione di O, Ω e Θ è nel capitolo 2 §2.

§1 · Formule e fatti da sapere

Cosa devi avere in testa

Ordine di crescita, dal più lento al più veloce: 1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n!

Logaritmi: log(a·b) = log a + log b · log(aᵏ) = k·log a, quindi log(2ⁿ) = n · la base non conta dentro Θ.

Somme: Σ i = Θ(n²) · Σ iᵏ = Θ(nᵏ⁺¹) · Σ log i = log(n!) = Θ(n log n) · Σ 2ⁱ = Θ(2ⁿ).

Master Theorem (forma del corso)

Per T(n) = a·T(n/b) + Θ(nβ) calcola α = logb a:

α > β ⇒ Θ(nα) · α = β ⇒ Θ(nα log n) · α < β ⇒ Θ(nβ)

Con una sola chiamata ricorsiva a = 1, quindi α = 0. Un costo costante è n⁰, quindi β = 0.

Ricorrenze per sottrazione

T(n) = T(n−1) + f(n) ⇒ T(n) = Σᵢ₌₁ⁿ f(i). Il Master Theorem non si applica: si srotola (metodo iterativo).

T(n) = 2T(n−1) + 1 ⇒ Θ(2ⁿ).

Verifica · §1

3 domande

T(n) = T(n/2) + 1. Quanto vale?

a = 1, b = 2: α = log₂ 1 = 0. Il costo extra è costante: β = 0. α = β ⇒ Θ(n⁰ log n) = Θ(log n).

T(n) = 4T(n/2) + n. Quanto vale?

α = log₂ 4 = 2 > β = 1 ⇒ Θ(nα) = Θ(n²).

T(n) = T(n−1) + n. Quanto vale?

È per sottrazione: il Master Theorem non vale. Srotolando: n + (n−1) + … + 1 = n(n+1)/2 = Θ(n²).

§3 · Procedura passo-passo

Come si scrive la soluzione

  1. Prima mystery2, la funzione più interna: quante chiamate ricorsive (a), su quale input (n/b oppure n−1), quanto costa il resto della funzione. Scrivi T′(n) con il caso base e risolvila.
  2. Poi mystery1: ogni chiamata mystery2(x) costa T′(x), sull'argomento passato e non per forza su n. Se x è costruito da un ciclo, calcola prima il suo valore.
  3. Scrivi l'equazione di mystery1 e risolvila.
  4. Risultato in Θ, tenendo solo il termine che cresce di più.

Esercizio 4.1 · scritto del 10/01/2024

mystery1 con n−1 e mystery2 con n/4

mystery1(n):  if n ≤ 0: return 1
              else: return mystery1(n−1) + mystery2(n)
mystery2(n):  if n ≤ 0: return 1
              else: return mystery2(n/4) + n/4

Quanto vale T(n) di mystery1?

Aprire la soluzione qui sotto per i passaggi.

Soluzione

  1. mystery2: una chiamata su n/4 (a = 1, b = 4). Il resto, + n/4, è un'operazione aritmetica: costa 1, quindi β = 0.

    T′(n) = T′(n/4) + 1 ⇒ α = log₄ 1 = 0 = β ⇒ T′(n) = Θ(log n)

  2. mystery1: una chiamata su n−1 (sottrazione) più mystery2(n), che costa Θ(log n).

    T(n) = T(n−1) + log n

  3. Srotolando:

    T(n) = log n + log(n−1) + … + log 1 + T(0) = Σ log i + 1 = log(n!) + 1

  4. T(n) = Θ(n log n)

§5 · Trappole tipiche

Dove si perdono punti

Un'operazione aritmetica non è un ciclo

return mystery2(n/2) + n² + n + 1 costa 1 oltre alla chiamata: n² è un valore calcolato in un passo, non n² operazioni.

Conta l'argomento della chiamata

Se k raddoppia n volte (k = 2ⁿ) e poi chiami mystery2(k) di costo logaritmico, il costo è log(2ⁿ) = n, non log n. È la trappola più frequente negli scritti 2025–26.

Ciclo con chiamate che crescono

for i = 1..n: k = 3k; mystery2(k) con mystery2 logaritmica costa Σ log(3ⁱ) = Σ i·log 3 = Θ(n²), non n log n (scritto del 09/01/2026).

  • Il valore restituito non è il costo: mystery1 può restituire un numero enorme e costare poco.
  • Il Master Theorem non si usa per T(n−1).
  • Scrivi sempre il caso base e tutti i passaggi: senza, il punteggio è parziale anche con il risultato giusto.

Esercizio 6.1 · scritto del 24/01/2024

Un while che dimezza e una mystery2 quadratica

mystery1(n):  x = 0
              while n ≥ 1:  n = n/2;  x = x + 1
              return mystery2(x)
mystery2(n):  if n ≤ 0: return 1
              else: x = 0
                    for i = 1..n:  for j = 1..n:  x = x + n
                    return mystery2(n/2) + log n − x
Soluzione

  1. mystery2: una chiamata su n/2 più un doppio ciclo da n·n operazioni.

    T′(n) = T′(n/2) + n² ⇒ α = 0 < 2 = β ⇒ T′(n) = Θ(n²)

  2. Il while dimezza n finché è ≥ 1: fa log₂ n + c iterazioni, e alla fine x = log₂ n + c.

  3. mystery1 costa il while più la chiamata su x:

    T(n) = Θ(log n) + T′(log n) = Θ(log n) + Θ(log² n)

  4. T(n) = Θ(log² n)

Esercizio 6.2 · due chiamate

f(n) = f(n/2) + f(n/2) + n

f(n):  if n ≤ 1: return 1
       else: return f(n/2) + f(n/2) + n
Soluzione

  1. Due chiamate su n/2 (a = 2, b = 2). Attenzione: + n è un'operazione aritmetica e costa 1, quindi β = 0.

    T(n) = 2T(n/2) + 1 ⇒ α = log₂ 2 = 1 > 0 = β

  2. T(n) = Θ(n)

Esercizio 6.3 · sottrazione

Un ciclo e una chiamata su n−1

g(n):  if n ≤ 0: return 0
       for i = 1..n: x = x + i
       return g(n−1)
Soluzione

  1. Il ciclo costa n, poi c'è una chiamata su n−1.

    T(n) = T(n−1) + n = n + (n−1) + … + 1 = n(n+1)/2

  2. T(n) = Θ(n²)
