JavaScript: il linguaggio

Il linguaggio in sé: tipi, uguaglianza, funzioni, oggetti e prototipi, array. Sono le domande "cosa stampa questo codice?" del quiz 2026 (forEach, null e undefined, Date) e la base di tutto quello che viene dopo.

Prima di iniziare · cosa ti serve

Le basi di programmazione che conosci già (variabili, if, cicli, funzioni). Per provare il codice apri il browser, premi F12 → Console e scrivi lì: è il modo più veloce per capire JavaScript. Le slide del prof su JavaScript non sono ancora uscite: questo capitolo segue gli appunti del corso degli anni scorsi e le domande d'esame, e va ricontrollato quando escono.

§0 · Orientamento

Cosa chiedono all'esame

  • Prevedere il risultato di piccoli frammenti: forEach contro map, "5" + 7, == contro ===, typeof null.
  • null contro undefined; var, let, const.
  • map, filter, reduce, anche come domanda aperta con l'esempio del carrello.
  • Ereditarietà a prototipi contro classi (scritto del 10/01/2025).
  • Date: perché si possono sottrarre due date.
§1 · Esecuzione

Dove e come si esegue

JavaScript (standardizzato come ECMAScript) gira nel browser e, con Node.js, sul server. Nella pagina si inserisce in tre modi: dentro un tag <script>…</script>, in un file esterno <script src="app.js"></script> (il modo migliore), oppure in un attributo di evento come onclick="…" (da evitare).

Si esegue in modo sincrono, appena lo script viene letto, oppure asincrono, in risposta a un evento (click, tasto, fine di un caricamento, timer).

Output

console.log(x) scrive nella console del browser (domanda del 2026) · alert(x) apre una finestra · elemento.textContent = x o innerHTML modifica la pagina · document.write è da evitare.

§2 · Basi

Variabili e tipi

var, let, const

let: variabile con visibilità di blocco (il blocco tra graffe in cui è dichiarata). · const: come let ma non si può riassegnare; se contiene un oggetto o un array, il contenuto si può comunque modificare (const a = []; a.push(1) è valido). · var: vecchia, visibilità di funzione e "hoisting" (la dichiarazione viene spostata in cima): da non usare.

I tipi

Le variabili non hanno tipo, i valori sì. Tipi primitivi: number (interi e decimali insieme; ci sono anche NaN e Infinity), string, boolean, undefined, null, bigint, symbol. Tutto il resto è object: oggetti, array, funzioni, date.

null e undefined

undefined: "non è stato assegnato niente". È il valore di una variabile dichiarata e mai assegnata, di un parametro non passato, di una proprietà che non esiste, e il risultato di una funzione senza return. · null: "nessun valore", assegnato apposta dal programmatore. · null == undefined → true · null === undefined → false · typeof undefined → "undefined" · typeof null → "object" (un errore storico del linguaggio).

typeof restituisce una stringa: typeof 3 "number", typeof NaN "number" (!), typeof [] "object" (per gli array si usa Array.isArray(x)), typeof function(){} "function".

§3 · Trappole

Uguaglianza, conversioni e valori "falsy"

== contro ===

== confronta dopo aver convertito i tipi: 5 == "5" true, 0 == false true, "" == 0 true. · === confronta senza conversioni (stesso tipo e stesso valore): 5 === "5" false. Si usa sempre === (e !==). NaN === NaN è false: per controllarlo si usa Number.isNaN(x).

L'operatore + e le conversioni

Se uno dei due operandi è una stringa, + concatena: "5" + 7 → "57", 1 + 2 + "3" → "33" (prima 1+2 = 3, poi 3 + "3"). Gli altri operatori aritmetici convertono in numero: "5" * 2 → 10, "5" - 2 → 3, "ciao" * 2 → NaN.

Falsy: nelle condizioni valgono come falso false, 0, "", null, undefined, NaN; tutto il resto è "truthy", compresi "0", [] e {}. Gli operatori a ?? b (b se a è null o undefined) e a?.b (accesso sicuro: undefined invece di un errore) sono molto usati.

Verifica · §2–§3

5 domande

Quale affermazione su undefined e null è corretta?

Uguali con ==, diversi con ===. Una variabile non assegnata vale undefined; null si assegna esplicitamente.

Quanto vale "3" + 4 + 5?

Da sinistra: "3" + 4 = "34", poi "34" + 5 = "345". Al contrario, 3 + 4 + "5" darebbe "75".

const lista = [1, 2]; lista.push(3); Cosa succede?

const impedisce di riassegnare la variabile (lista = […] darebbe errore), non di modificare l'array a cui punta.

Quale di questi valori è "truthy"?

"0" è una stringa non vuota, quindi è truthy. Anche [] e {} sono truthy.

Quanto vale typeof NaN?

NaN ("Not a Number") è un valore speciale del tipo number.

§4 · Funzioni

Funzioni, arrow function e closure


function doppio(n) { return n * 2; }          // dichiarazione
const triplo = function (n) { return n * 3; }; // espressione
const quadruplo = n => n * 4;                  // arrow function (return implicito)
doppio();                                      // n vale undefined → risultato NaN, nessun errore

Le funzioni sono valori: si salvano in variabili, si passano come argomento (callback) e si restituiscono da altre funzioni. I parametri mancanti valgono undefined, e si possono dare valori di default: function f(x = 0).

Arrow function: sintassi breve; in più non hanno un loro this (usano quello del contesto in cui sono scritte), il che le rende comode come callback.

Closure

Una funzione "ricorda" le variabili dello scope in cui è stata creata, anche dopo che quella funzione esterna è terminata.


function contatore() { let n = 0; return () => ++n; }
const c = contatore();
c(); c();   // 1, poi 2: n sopravvive dentro la closure
§5 · Oggetti

Oggetti, prototipi e classi

In JavaScript un oggetto è un insieme di coppie chiave-valore, e i valori possono essere anche funzioni (metodi) e altri oggetti: const p = { nome: "Ada", eta: 36, saluta() { return "Ciao " + this.nome; } }. Si accede con p.nome o p["nome"] (con le parentesi la chiave può essere una variabile). Gli array sono oggetti con chiavi numeriche.

Ereditarietà a prototipi (domanda del 10/01/2025)

Ogni oggetto ha un collegamento a un altro oggetto, il suo prototipo. Se una proprietà non c'è nell'oggetto, la si cerca nel prototipo, poi nel prototipo del prototipo, e così via: è la catena dei prototipi. Così ogni array "ha" push e map: stanno in Array.prototype.
Differenza concettuale: nei linguaggi class-based (Java) le classi sono "progetti" statici e gli oggetti sono istanze create da quei progetti. Nel prototype-based gli oggetti ereditano direttamente da altri oggetti, e la catena si può modificare a runtime.
Vantaggi pratici: si può creare un oggetto a partire da un altro senza definire una classe (Object.create(base)); si possono aggiungere metodi a tutte le istanze esistenti modificando il prototipo; i metodi sono condivisi e non copiati in ogni oggetto, quindi si risparmia memoria.


const animale = { verso() { return this.nome + " fa " + this.suono; } };
const cane = Object.create(animale);          // il prototipo di cane è animale
cane.nome = "Fido"; cane.suono = "bau";
cane.verso();                                  // "Fido fa bau" (verso viene da animale)
animale.dorme = function () { return this.nome + " dorme"; };
cane.dorme();                                  // funziona subito: la catena è viva

class Gatto { constructor(nome) { this.nome = nome; } miagola() { return "miao"; } }
// la sintassi class (dal 2015) è "zucchero sintattico": sotto usa sempre i prototipi
§6 · Array

Array e i loro metodi

I metodi da sapere

push / pop (aggiungi o togli in fondo), length, includes(x), indexOf(x), slice, splice, join, sort.
Metodi con callback (ricevono una funzione che viene chiamata per ogni elemento):
forEach(f): esegue f su ogni elemento per i suoi effetti; restituisce undefined.
map(f): nuovo array della stessa lunghezza con i risultati di f.
filter(f): nuovo array con gli elementi per cui f restituisce true.
reduce((acc, x) => …, iniziale): accumula tutto in un solo valore.
find(f): il primo elemento che soddisfa f (o undefined) · some(f) / every(f): true se almeno uno / tutti soddisfano f.
map, filter e reduce non modificano l'array originale.


const carrello = [{ nome: "Penna", prezzo: 1.5, qty: 2 }, { nome: "Gomma", prezzo: 0.8, qty: 0 }];
const disponibili = carrello.filter(p => p.qty > 0);                   // solo la penna
const nomi        = disponibili.map(p => p.nome);                       // ["Penna"]
const totale      = disponibili.reduce((acc, p) => acc + p.prezzo * p.qty, 0); // 3

Verifica · §4–§6

5 domande

Quanto vale [1,2,3].map(x => x * 2)?

map restituisce un nuovo array. Con forEach il risultato sarebbe undefined.

Quanto vale [5, 12, 8, 20].filter(x => x > 10).length?

filter tiene 12 e 20, quindi length è 2.

Quanto vale [1,2,3,4].reduce((a, x) => a + x, 10)?

L'accumulatore parte da 10 e si sommano 1+2+3+4 = 10, quindi 20.

Nell'ereditarietà a prototipi, dove cerca JavaScript una proprietà che l'oggetto non ha?

Se non la trova fino in fondo alla catena (Object.prototype e poi null) restituisce undefined, senza errore.

Cosa NON hanno le arrow function rispetto alle funzioni normali?

Usano il this del contesto in cui sono scritte: per questo sono comode nelle callback e nei metodi dei componenti.

§7 · Dati

JSON e Date

JSON

È la notazione degli oggetti JavaScript usata come formato di scambio, con regole più rigide: chiavi sempre tra virgolette doppie, niente funzioni, niente undefined, niente commenti, niente virgola dopo l'ultimo elemento. JSON.stringify(oggetto) trasforma un oggetto in testo; JSON.parse(testo) trasforma il testo in oggetto.

Date (domanda del 2026)

new Date() è adesso; new Date("2027-01-12"); new Date(2027, 0, 12): i mesi partono da 0, quindi 0 è gennaio! Internamente una data è il numero di millisecondi dal 1° gennaio 1970 (UTC). Per questo fine - inizio funziona: la sottrazione converte le date in numero con valueOf() e dà la differenza in millisecondi. Per avere i giorni: (fine - inizio) / (1000*60*60*24).

Verifica · §7

2 domande

Quale di questi è JSON valido?

In JSON le chiavi e le stringhe vogliono le virgolette doppie, e non è ammessa la virgola finale.

new Date(2027, 1, 1) che giorno è?

I mesi partono da 0: 1 = febbraio. Il giorno invece parte da 1.
