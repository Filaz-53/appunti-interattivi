Il formato dell'esame

Dalla scheda 2026/27

§3 · Allenamento

Quiz · CSS e HTML

CSS e HTML

6 domande

Un elemento ha position: sticky ma durante lo scroll non resta attaccato. Qual è la causa più probabile?

Sticky ha bisogno di almeno una soglia (top, bottom, left o right) diversa da auto sull'asse dello scroll: è la soglia oltre la quale l'elemento si "attacca".

Contenitore con display: flex e direzione di default. Come centri i figli in orizzontale?

Con flex-direction: row l'asse principale è orizzontale e justify-content agisce sull'asse principale. align-items agisce sull'asse trasversale (qui verticale).

Cosa fa object-fit: cover su un'immagine?

La prima opzione descrive contain, la terza fill. Il CSS non cambia mai il file scaricato.

A cosa sono relative le unità rem e vh?

em è relativo al font dell'elemento stesso (o del genitore per font-size), rem a quello di <html>. vw e vh sono l'1% di larghezza e altezza del viewport. Le unità assolute sono px, cm, pt…

Un <button> dentro un <form>, senza attributo type, quando viene cliccato…

Il default è submit. Per un pulsante che esegue solo JavaScript si scrive type="button": è un errore classico anche nei progetti.

Qual è la differenza tra markup presentazionale e descrittivo?

Esempio: <b>, <font> sono presentazionali, <strong> e <h1> descrittivi. Separare contenuto e presentazione è proprio il motivo per cui è nato il CSS.

§4 · Allenamento

Quiz · JavaScript

JavaScript e asincronia

5 domande

Quanto vale res dopo const res = [1,2,3].forEach(x => x * 2);?

forEach serve per gli effetti collaterali e restituisce sempre undefined. Per ottenere [2, 4, 6] si usa map.

Quale affermazione su null e undefined è corretta?

Con l'uguaglianza debole sono uguali, con quella stretta no. typeof null è "object" (un errore storico del linguaggio). undefined è il valore di una variabile dichiarata e mai assegnata; null si assegna per dire "nessun valore".

Perché una callback Ajax non può "restituire" il dato alla funzione che ha fatto la richiesta?

La richiesta è asincrona: la funzione prosegue e termina, e la callback arriva più tardi dall'event loop. Il dato va usato dentro la callback, oppure si usa una Promise o async/await.

Tre chiamate Ajax A → B → C, dove ognuna usa il risultato della precedente. Come le scrivi?

Promise.all va bene per chiamate indipendenti. Se B dipende da A bisogna aspettare A: si fa con la catena di .then o con await in sequenza (l'alternativa vecchia sono le callback annidate, il "callback hell").

Perché in JavaScript dataFine - dataInizio, tra due oggetti Date, dà un numero?

L'operatore − chiama valueOf(), che per un Date restituisce il timestamp in millisecondi. Il risultato è la differenza in millisecondi.

§5 · Allenamento

Quiz · HTTP, REST e URI

HTTP, REST, URI

5 domande

Un client invia per errore tre volte la stessa PUT allo stesso URI. Cosa dovrebbe succedere?

PUT, GET, DELETE sono idempotenti: ripeterli non cambia il risultato. POST no: tre POST possono creare tre risorse.

Perché GET è definito un metodo "sicuro"?

"Sicuro" vuol dire senza effetti collaterali (sola lettura), non protetto. Ogni metodo sicuro è anche idempotente, ma non viceversa (PUT è idempotente ma non sicuro).

Quando una API risponde 201 Created a una POST?

201 indica la creazione, e Location dice l'URI della nuova risorsa. Una POST riuscita che non crea niente risponde 200 (o 204 senza corpo); "ricevuta ma non ancora elaborata" è 202.

A cosa serve l'header Accept in una richiesta?

Il formato di ciò che invio sta in Content-Type; la compressione si chiede con Accept-Encoding; l'autenticazione usa Authorization.

La pagina è https://uni.it/corsi/web/lez/1.html e contiene il link ../slide/a.pdf. Qual è l'URI assoluto?

Si parte dalla cartella del documento (/corsi/web/lez/); .. sale di un livello a /corsi/web/ e poi si aggiunge slide/a.pdf.

Quiz · Codifica dei caratteri

Lo schema di UTF-8 da sapere

0xxxxxxx = carattere ASCII in 1 byte · 110xxxxx = inizio di un carattere da 2 byte · 1110xxxx = inizio di uno da 3 · 11110xxx = inizio di uno da 4 · 10xxxxxx = byte di continuazione, mai il primo.

Codifica

3 domande

In UTF-8, un byte 10xxxxxx trovato come primo byte di un carattere indica…

10xxxxxx è sempre un byte di continuazione: se compare per primo, il flusso è corrotto o è stato tagliato a metà carattere.

Cos'è il Basic Multilingual Plane (BMP)?

65 536 posizioni rappresentabili con 16 bit (era lo spazio di UCS-2). Emoji e caratteri rari stanno nei piani superiori.

Quanti byte usa UTF-8 per la lettera "A" (U+0041) e per "è" (U+00E8)?

Fino a U+007F (ASCII) basta 1 byte, identico ad ASCII. Da U+0080 a U+07FF ne servono 2. In ISO Latin-1 invece "è" occupa 1 byte: per questo i testi Latin-1 letti come UTF-8 mostrano caratteri strani.

Quiz · Server, framework, Semantic Web

Il resto del programma

5 domande

Nella convenzione error-first di Node.js, la callback riceve…

Esempio: fs.readFile("a.txt", (err, data) => { if (err) return gestisci(err); usa(data); }).

In MongoDB, cos'è _id?

Ogni documento ha un _id unico. L'ObjectId generato contiene anche un timestamp di creazione.

A cosa serve lo Shadow DOM nei Web Components?

È l'incapsulamento: gli stili del componente non escono e quelli della pagina non entrano.

Differenza tra Server-Side Rendering (SSR) e Client-Side Rendering (CSR)?

Con SSR la prima visualizzazione è più veloce e indicizzabile; con CSR la pagina arriva quasi vuota e il JS la costruisce.

In Turtle, cosa significa la parola a in :fido a :Cane .?

La tripla dice che fido è di tipo Cane. I blank node invece si scrivono _:nome oppure tra parentesi quadre [ … ].

Domanda aperta · JavaScript

Carrello: map, filter e reduce

Hai prodotti = [{name:"Penna", price:1.5, qty:2}, …]. Come useresti map, filter e reduce per: (1) i prodotti con qty > 0, (2) l'elenco dei nomi, (3) il totale? Perché è meglio di un ciclo?

Risposta modello

  1. const disponibili = prodotti.filter(p => p.qty > 0); → filter tiene gli elementi per cui la funzione dà true.

  2. const nomi = disponibili.map(p => p.name); → map trasforma ogni elemento e restituisce un nuovo array della stessa lunghezza.

  3. const totale = disponibili.reduce((acc, p) => acc + p.price * p.qty, 0); → reduce accumula in un solo valore, partendo da 0.

  4. Sono dichiarativi (dicono cosa ottenere, non come scorrere gli indici), non modificano l'array originale, si concatenano e riducono gli errori sugli indici

Domanda aperta · HTML

I form HTML e l'attributo action

Risposta modello

  1. Un <form> raccoglie dati dall'utente e li invia al server come coppie nome=valore.

  2. action è l'URI a cui si inviano i dati; method è il metodo HTTP: GET mette i dati nella query string, POST nel corpo della richiesta.

  3. È fatto di controlli con un attributo name: <input> (con i vari type: text, email, password, checkbox, radio…), <select>, <textarea>, <button type="submit">, più <label> per l'accessibilità.

  4. Esempio: <form action="/login" method="post"><label>Email <input type="email" name="email" required></label><button>Entra</button></form>

Domanda aperta · Architettura

Cosa sono le CDN?

Risposta modello

  1. Una Content Delivery Network è una rete di server distribuiti in molte aree geografiche che mantengono copie di risorse statiche (librerie JS e CSS, immagini, video).

  2. Vantaggi: minore latenza (risponde il server più vicino), meno carico sul server d'origine, caching condiviso tra siti (la stessa libreria è già nella cache del browser), resistenza ai picchi e agli attacchi DDoS.

  3. Esempi: jsDelivr, cdnjs, unpkg (da cui si includono Bootstrap, Tailwind e le icone); Cloudflare, Akamai
