Dare significato ai dati in modo che anche le macchine li capiscano: RDF (tutto è una tripla soggetto-predicato-oggetto), la sintassi Turtle, le ontologie, le interrogazioni SPARQL. §1 · Idea

Semantic Web e Linked Data

Il Semantic Web (Berners-Lee) vuole un web di dati con significato esplicito, elaborabili e collegabili dalle macchine, non solo pagine leggibili dagli umani. Il prof lo definisce "molto ambizioso, forse condannato dall'ambizione". Il Linked Data è la versione più modesta e di successo: dati pubblicati con URI e collegati tra loro, anche senza grandi ontologie. Gli Open Linked Data (LOD) sono i dati aperti in questo formato (per esempio quelli della Pubblica Amministrazione, o DBpedia, che pubblica Wikipedia come dati).

I quattro principi del Linked Data

1. Usa gli URI per dare un nome alle cose. 2. Usa URI HTTP, così si possono "aprire" (dereferenziare). 3. Quando qualcuno apre l'URI, fornisci informazioni utili negli standard (RDF, SPARQL). 4. Includi link ad altri URI, così si scoprono altre cose.

§2 · Modello

RDF: triple e grafi

La tripla

RDF (Resource Description Framework) esprime ogni informazione come un'affermazione fatta da tre parti: soggetto – predicato – oggetto.
Soggetto: una risorsa, identificata da un URI (o un blank node).
Predicato: la proprietà o relazione, sempre un URI.
Oggetto: un'altra risorsa (URI o blank node) oppure un letterale (una stringa, un numero, una data, eventualmente con tipo o lingua).

Un insieme di triple forma un grafo: le risorse sono i nodi, i predicati sono gli archi orientati. Esempio dagli appunti: "Umberto Eco è autore del Nome della Rosa" diventa 5 triple. Eco è una persona; si chiama "Umberto Eco"; ha scritto il libro B; B è un libro; B si intitola "Il nome della rosa".

Formati di serializzazione (modi di scrivere lo stesso grafo): Turtle (compatto e leggibile), JSON-LD (in JSON, molto usato nelle pagine web per i motori di ricerca), RDF/XML (il primo standard, verboso), N-Triples.

Pro e contro

Pro: modello semplice; i dati sono un grafo; è modulare (anche informazioni parziali formano un grafo coerente, e si possono unire grafi diversi); con OWL si può ragionare sui dati. Contro: i dati sono frammentati in moltissime triple (un database medio può diventare miliardi di triple); le relazioni con più di due partecipanti (n-arie) sono scomode da rappresentare.

Ragionamento monotono e mondo aperto

Nel Semantic Web vale l'ipotesi del mondo aperto: se un fatto non è scritto, non si sa, non è automaticamente falso. Il ragionamento è monotono: aggiungere nuove triple non invalida mai le conclusioni già tratte, al massimo ne aggiunge altre. Ogni tripla è un'affermazione indipendente che si somma alle altre.

§3 · Sintassi

Turtle


@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix dc:   <http://purl.org/dc/terms/> .
@prefix ex:   <http://example.org/> .

ex:eco  a  foaf:Person ;                       # "a" = rdf:type
        foaf:name  "Umberto Eco" ;             # letterale stringa
        foaf:made  ex:nomeDellaRosa , ex:pendolo .   # due oggetti, stesso predicato

ex:nomeDellaRosa  dc:title  "Il nome della rosa"@it ;   # letterale con lingua
                  dc:date   "1980"^^<http://www.w3.org/2001/XMLSchema#gYear> .

<http://example.org/umberto> foaf:knows _:qualcuno .  # URI completo e blank node
_:qualcuno foaf:name "Un amico" .
ex:eco foaf:based_near [ foaf:name "Bologna" ] .         # blank node con parentesi quadre
Le regole

@prefix definisce un'abbreviazione per un URI: foaf:name sta per l'URI completo. Ogni affermazione finisce con un punto. Il punto e virgola ; ripete lo stesso soggetto con un altro predicato. La virgola , ripete lo stesso soggetto e lo stesso predicato con un altro oggetto. Gli URI completi stanno tra < >. I letterali sono tra virgolette, con la lingua (@it) o il tipo (^^xsd:date). La parola a è l'abbreviazione di rdf:type.
Blank node (nodo anonimo): una risorsa senza URI, scritta _:nome o [ … ]. Può essere soggetto o oggetto, mai predicato. Un letterale non può mai essere soggetto né predicato.

Verifica · §2–§3

5 domande

In Turtle, cosa abbrevia la parola a?

ex:fido a ex:Cane . vuol dire che fido è di tipo Cane. Domanda del 12/02/2026.

Quale tripla Turtle è non valida?

Il predicato deve essere un URI: non può essere un blank node né un letterale.

ex:eco foaf:made ex:libro1 , ex:libro2 . Quante triple sono?

La virgola ripete soggetto e predicato: eco made libro1, ed eco made libro2.

Cosa può essere l'oggetto di una tripla RDF?

L'oggetto è l'unica posizione in cui possono stare i letterali.

Cosa vuol dire che il ragionamento nel Semantic Web è monotono?

Si aggiungono conoscenze, non si ritrattano. L'ultima opzione descrive il mondo chiuso, che non è l'ipotesi del Semantic Web.

§4 · Significato

Ontologie: RDFS e OWL

Un'ontologia è un vocabolario condiviso che definisce classi, proprietà e relazioni tra di esse in un dominio. Vocabolari noti: FOAF (persone e relazioni), Dublin Core (metadati di documenti: title, creator, date), schema.org (usato dai motori di ricerca).

RDFS e OWL

RDFS (RDF Schema): rdfs:Class, rdfs:subClassOf (ogni Cane è un Animale), rdfs:subPropertyOf, rdfs:domain e rdfs:range (a che tipo di soggetto e di oggetto si applica una proprietà), rdfs:label.
OWL (Web Ontology Language) è più espressivo, basato sulle logiche descrittive: classi disgiunte, proprietà inverse, transitive e funzionali, owl:sameAs (due URI indicano la stessa cosa), cardinalità. Permette a un reasoner di dedurre nuove triple: se Fido è un Cane e Cane è sottoclasse di Animale, allora Fido è un Animale.

§5 · Interrogare

SPARQL

SPARQL è il linguaggio per interrogare i grafi RDF (un po' come SQL per i database relazionali). Una query descrive un pattern di triple con variabili (?x), e il motore cerca nel grafo tutte le assegnazioni delle variabili che rendono vero il pattern.


PREFIX foaf: <http://xmlns.com/foaf/0.1/>
PREFIX dc:   <http://purl.org/dc/terms/>

SELECT ?autore ?titolo
WHERE {
  ?autore a foaf:Person ;
          foaf:made ?libro .
  ?libro  dc:title ?titolo .
  FILTER (lang(?titolo) = "it")
}
ORDER BY ?titolo
LIMIT 10
Le forme di query e cosa restituiscono

SELECT: una tabella di risultati, con una colonna per variabile e una riga per ogni combinazione di valori (binding) che soddisfa il pattern. · ASK: true o false (esiste almeno una soluzione?). · CONSTRUCT: un nuovo grafo RDF costruito dai risultati. · DESCRIBE: un grafo con le informazioni su una risorsa. Clausole utili: FILTER, OPTIONAL, ORDER BY, LIMIT, DISTINCT. Gli endpoint SPARQL sono servizi web che accettano query via HTTP (es. DBpedia).

Verifica · §4–§5

3 domande

Cosa restituisce una query SPARQL SELECT eseguita su un dataset RDF?

true o false lo restituisce ASK; un grafo lo restituisce CONSTRUCT.

Ontologia: Cane rdfs:subClassOf Animale; ex:fido a Cane. Cosa deduce un reasoner?

L'appartenenza a una sottoclasse implica l'appartenenza alla superclasse: è l'inferenza tipica di RDFS.

Quale formato serializza RDF dentro JSON?

JSON-LD ("Linked Data") si inserisce anche nelle pagine HTML per dare dati strutturati ai motori di ricerca.
