§1 · Nome della sezione

Titolo della sezione

Paragrafo normale. Tienilo sotto le 4–5 righe; usa grassetto per il concetto chiave e codice per nomi di metodi o file.

Definizione

Il riquadro con il bordo colorato serve per definizioni e teoremi, copiati fedelmente dal materiale del corso.

Le note a margine sono scritte «a penna»: frasi brevi, un'osservazione alla volta. Sugli schermi larghi stanno a destra del paragrafo che le precede.
Attenzione

Il riquadro giallo è per gli errori tipici e le trappole d'esame.


// Blocco di codice con evidenziazione Java e pulsante Copia.
// Scrivi < e > come &lt; e &gt;. Togli data-lang per un blocco senza colori.
int somma = 0;
for (int i = 0; i < n; i++) somma += i;
  1. Nome-Procedura(A, n)
  2. per i = 1 a n
  3. se A[i] < 0 allora ritorna i
  4. ritorna nil
